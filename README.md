# Job Application & Reachout Automation

Automated PM job search system — finds roles, scores fit, reaches out to recruiters, tracks everything, and WhatsApps a daily briefing.

Built for: **Charmi Shah** — PM/APM/TPM job hunt across SF, Dubai, and remote.

---

## What It Does Every Morning

1. **Scrapes** LinkedIn + Indeed for PM/APM/TPM job postings from the last 7 days
2. **Scores** each company 1–5 against your profile — only 4-5/5 pass
3. **Finds** the recruiter or hiring manager email at each company via Hunter.io
4. **Cross-checks** your LinkedIn connections — warm vs cold outreach
5. **Sends** personalized Gmail with tailored resume PDF attached
6. **Logs** every contact to Notion with status tracking
7. **WhatsApps** you: today's ideal-fit jobs, who we're reaching out to, their LinkedIn profiles, and reply stats

---

## Daily Flow

### Phase 1 — 7am (automatic via GitHub Actions, Mac can be off)
```
GitHub Actions runs --discover
→ Scrapes jobs, scores them, finds recruiter contacts
→ WhatsApp arrives on your phone with today's plan + LinkedIn links
→ No emails sent yet
```

### Phase 2 — When you open your laptop (~15 min)
```
1. Check WhatsApp → review targets, tap their LinkedIn links
2. Open Claude Desktop → /job-matching tailor my resume for [Company]
3. PDFs saved to outputs/ folder automatically
4. python3.11 main.py --send → emails fire with resume attached
```

## Commands

```bash
# Phase 1: scrape + score + WhatsApp plan (no emails)
python3.11 main.py --discover

# Phase 2: send emails with tailored resumes attached
python3.11 main.py --send

# Preview full run, no emails sent
python3.11 main.py --dry

# Resend WhatsApp digest only
python3.11 main.py --digest
```

## Setup

### 1. Clone and install
```bash
git clone https://github.com/CharmiShah26/job-application-and-reachout.git
cd job-application-and-reachout
pip3.11 install -r requirements.txt
```

### 2. Create `.env` file
```
APOLLO_API_KEY=your_key
HUNTER_API_KEY=your_key
GMAIL_SENDER=your@gmail.com
NOTION_TOKEN=your_token
NOTION_DATABASE_ID=your_db_id
TWILIO_ACCOUNT_SID=your_sid
TWILIO_AUTH_TOKEN=your_token
TWILIO_WHATSAPP_FROM=whatsapp:+14155238886
YOUR_WHATSAPP_NUMBER=whatsapp:+1XXXXXXXXXX
```

### 3. Authorize Gmail (one-time)
```bash
python3.11 setup_gmail.py
```

### 4. Add LinkedIn connections CSV (for warm/cold detection)
Download from LinkedIn → Settings → Data Privacy → Get a copy of your data → Connections
Save as `data/Connections.csv`

### 5. GitHub Actions (cloud, no Mac needed)
Add all `.env` values as repository secrets under Settings → Secrets → Actions.
The workflow runs automatically every weekday at 7am SF time.
